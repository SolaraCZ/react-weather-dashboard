# Weather Dashboard

A high-contrast, utility-focused weather dashboard built with React and Vite, utilizing the OpenWeatherMap API.

Live Demo: [https://solaracz.github.io/react-weather-dashboard/](https://solaracz.github.io/react-weather-dashboard/)

## Tech Stack

* **Frontend:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS (v3)
* **API:** OpenWeatherMap API (2.5)
* **Hosting / CI:** GitHub Pages, GitHub Actions
